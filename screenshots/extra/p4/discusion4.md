# Discusion 4

1. **Навіщо в програмуванні окремий тип для «так» і «ні»?**  
   Щоб зберігати результат умови: правда чи ні

2. **Як сказати !(a && b) людською мовою?**  
   Це означає, що хоча б одна з умов хибна

3. **Чим && відрізняється від &?**  
   && може зупинитися, коли вже ясно, що умова хибна, а & перевіряє обидві частини

4. **Чому програма не падає в if (x != null && x.name == "Іван"), хоча x порожній?**  
   Коли x порожній, друга частина умови не перевіряється

5. **Як запхати 32 відповіді «так/ні» в одне число?**  
   Відвести для кожної відповіді окремий біт

6. **Що швидше: n % 2 чи n & 1?**  
   Зазвичай різниці майже немає, а % 2 простіше читати
