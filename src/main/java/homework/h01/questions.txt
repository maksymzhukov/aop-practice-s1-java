1.Яку з чотирьох провалених задач розв'язує git log?
Команда git log розв'язує задачу відстеження історії змін (або пошуку моменту, коли все зламалося)

2.Яку — git diff?
Команда git diff показує точні почергові зміни між двома різними станами вашого Git-репозиторію

3.Яка з них не має розв'язку аж до заняття 10?
Питання «поєднання» не має розв’язку аж до заняття 10.

Чим програма відрізняється від алгоритму?
Алгоритм — це просто план дій або ідея, як вирішити задачу. А програма — це вже готовий код, написаний конкретною мовою програмування, який комп'ютер реально зможе запустити і виконати

Навіщо потрібні мови програмування, якщо процесор їх усе одно не розуміє?
Мови програмування потрібні тому, що вони є зручним перекладачем між людиною та процесором, який розуміє лише нулі та одиниці (машинний код)

Чи може комп'ютер зробити щось, чого йому не казали?
Ні, сам по собі не може. Він робить тільки те, що є в програмі. Але іноді результат може бути несподіваним, бо команди поєднуються між собою.

Чи є рецепт борщу алгоритмом?
Не зовсім, бо в рецепті є повно неточностей по типу "сіль на око", а компютеру потрібно чіткі цифри (скільки грамів,скільки хвилин)

Опишіть, як зав'язати шнурки, для того, хто ніколи їх не бачив.
Треба взяти два кінці шнурка, перехрестити їх та затягнути один під інший, далі треба зробити з кожного кінця по петельці, так само їх перехрестити, один кінець треба просунути у дірку, що утворилася знизу та міцно затягнути петлі в різні боки.

Програма правильно порахувала всі приклади з дошки. Чи Це доводить, що вона працює?
Ні, не доводить. Вона може помилятися на інших числах або на складніших випадках. Треба тестувати більше, особливо межові випадки
